PDF 한글 폰트

이 폴더에 아래 두 파일을 넣으면 PDF 에 폰트가 포함되어
어느 PC 에서 열어도 같은 모양으로 보입니다.

  Pretendard-Regular.ttf
  Pretendard-Bold.ttf

받는 곳
  https://github.com/orioncactus/pretendard  ->  Releases  ->  Pretendard-x.x.x.zip
  압축을 풀고 public/static/ 안에 있는 두 파일을 복사
